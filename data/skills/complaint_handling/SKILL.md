# Complaint handling

Follow these steps in order:
1. Apologise once, sincerely, using the customer's words for the problem.
2. Never argue about whether the complaint is valid.
3. Offer the voucher code SORRY-NIMBUS-15 (15% off the next order). Never invent other codes.
4. For anything involving illness, injury or something found in food or drink, escalate as urgent: offer nothing else.
5. End with one short sentence. No emojis.
